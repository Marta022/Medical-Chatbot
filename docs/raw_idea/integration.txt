Please modify Phase P5 of the project architecture.

The current design assumes the dataset consists of PDF files in `data/dataset/*.pdf`
and uses a PDF parser (PyMuPDF) to extract pages.

However, the dataset is now stored as a Markdown file:

data/dataset/document.md

The text has already been extracted from the original PDF.

Required changes:

1. Replace the PDF ingestion logic with Markdown ingestion.
2. Remove the dependency on PyMuPDF.
3. Implement a Markdown-aware loader that:
   - reads `document.md`
   - detects headings (#, ##, ###)
   - detects bullet and numbered lists
4. Map Markdown structure to the metadata schema.

Metadata fields should still include:
- source_file
- chapter
- section
- chunk_id

Page numbers are optional since the source is Markdown.

Chunking should operate on the Markdown structure rather than PDF pages.

Modify the following modules accordingly:

rag/chunking/load_documents.py
rag/chunking/strategies.py
ingestion/ingest_vectordb.py

Constraints:
- Do not modify the Qdrant ingestion logic.
- Do not modify the embedding pipeline.
- Only replace the document loader and structure detection logic.

Expected result:
The ingestion pipeline should load `document.md`,
perform semantic chunking,
and store chunks with metadata in Qdrant exactly as before.
